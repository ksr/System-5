IDE Interface Card
Last Updated: Mar. 8/2005
Rev. A of the IDE Interface card populated with a CF to IDE interface and 16MB CF card. Jumpers select the I/O ports
for IDE control and data read/write.
Description
This design is borrowed directly from Mike Riley's 8 bit IDE Interface. The only change is the addition of some jumper
blocks to select I/O ports. This is required to support compatibility of some older software of my own that used the
original ports.
