Memory Rev. B operational description  **UNTESTED*
Last Updated: Mar. 8/2005

Bus Buffering: 4050 Gates 7A-F and 8A-D buffer the bus address A0-7 and -MRD -MWR lines.

Address expansion: 4042 IC6 and IC9 demultiplex address A0-7 into A8-A15 using TPA. IC9 provide both A15 and -A15
required for 32K chip selection.

Chip Selection: 74LS32 IC14 Gate A generates chip select for the lower 32K (0x0000 - 0x7ffff) address range RAM 1
and EPROM 1. Chip select is generated by combining a low on A15 and active low on bus signal -VMA (see bus
description for more information on -VMA). Gate B generates chip select for RAM 2 and EPROM 2 using -A15 from IC9
and bus signal -VMA.

4K Bank Select: Each 4K block of the RAM and EPROM chips can be enabled or disabled from the memory map via a
74LS151. Each 8 to 1 74LS151 multiplexer is connect to A12, A13, A14 and a 32K bank select input. Each of the eight
multiplexer inputs is connected to a pull up resistor which places that multiplexer input in to the "disable state". An 8 x 3
jumper block for each 32K block of RAM/EPROM can enable a 4K block of either RAM or EPROM by connected it to
ground. A12, A13, A14 select the multiplexer input which is connected to the RAM or EPROM chip enable.

EPROM and RAM: Data D0-7 is connect directly to bus D0-7, Address A0-A7 is connect to buffered A0-A7, A8-A14 is
connected to address expansion IC6 and IC9.  Buffered -MRD is connected to -RD on the RAM and -OE (output enable)
on the EPROM. On the RAM -WR is connect to buffered -MWR.

LEDS:
Power is connected directly to the supply of the card
LED 1/RAM LO: Indicates a 4K block of the lower 32K RAM chip is enabled
LED 2/RAM HI: Indicates a 4K block of the upper 32K RAM chip is enabled
LED 3/EPROM LO: Indicates a 4K block of the lower 32K EPROM chip is enabled
LED 4/EPROM HI: Indicates a 4K block of the upper 32K EPROM chip is enabled
