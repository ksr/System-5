## Hardware design findings

From `hardware/TIMING-REVIEW.md` unless noted.

- **T1 (High), CPU card:** the 74LS374 (IC1) latches the high address on TPA's *rising* edge, with no guaranteed setup: −102 ns worst case. It works because a typical 1802 is early, but it is a race (intermittent boot failures or wrong reads). Suggested fix: clock the 374 from *inverted* TPA, using a spare 74LS05 inverter (IC6C or IC6E) with a stiff pull-up of about 1 kΩ. That gives about 471 ns of setup at 1.76 MHz. Apply it on the real card, or in a CPU Rev B redesign.
- **T2 (Medium), 6845 card:** register writes end with R/W (= -MWR) rising while E (= TPB) is still high, at any clock speed. It works on the HD6845; confirm with a scope.
- **6845 Rev B as fitted:** IC4 is a 74LS85, not the drawn 74S85, in the address compare gated by -VMA; IC9 is a 74AS175. The timing review used the Rev A netlist; recheck the decode path with the LS85 when the 6845 model moves to Rev B.
- **T3–T5 (Low), 6845 card:** E width against its 450 ns minimum (+18 ns), register-read data setup (−77 ns worst case) and hold (typical only). CRTC reads are rare.
- **T6 (Low), IDE card:** INP 3 into RAM, with drive data held +49 ns past WE. It fails worst case from about 2.2 MHz.
- **C2 (Small), CPU card:** after a boot-EPROM read, its output overlaps the next card by 28 ns plus R13's RC time. See question 5.
- **Not reviewed yet:** the reset/run circuit (IC3/IC4/IC5/U1 and its rework), the 1861's DMA timing, and electrical loading (fan-out, CMOS levels from LS outputs, rise times on long lines).

Or install before the move (video at 7000, old HBIOS), or skip the EPROM (CF built on the Mac). Once a card holds ELF/OS the OS EPROM is not needed: HBIOS `@FF00` boots from the card; keep the chip for rebuilding a card without a Mac. Note: `f_freemem` scans up from 0000 to the first byte that won't write, so it ends at the top of the video RAM (77FF today, E7FF then), where HBIOS keeps the cursor; ELF/OS kernel 135 doesn't use it, but programs that do would write over it either way.
- **IO card (1861 + keyboard) bring-up: later.** It is tied to the CPU card, so it waits for the CPU card redesign below.
- **Fix EXEC in the ELF/OS install ROM** (found 2026-11-01 in the emulator): the ROM's `EXEC` entry (C680-C69C) loads and runs at 7000, which is the 6845's video RAM on System-5 (the ROM was built for another memory map). Reassemble or patch it to load in RAM (for example 6000, like SAVE/DUMP/ASM), change its table entry at 80CF, and rebuild `../private-resources/elf/firmware/elfos-install-rom/with-basic/` (`build.py`).
